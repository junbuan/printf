Before and After Changes

1) Makefile dependency cleanup

Before:
- The Makefile still tried to build and link libft.
- It referenced a removed file name: ft_printf_utils.c.
- It had a typo in the main target variable: AME instead of NAME.

Example before:
SRC = ft_printf.c \
	ft_printf_utils.c
LIBFTDIR = libft
LIBFT = $(LIBFTDIR)/libft.a

After:
- The Makefile now builds only the local printf sources.
- It uses ft_printf.c and ft_helpers.c.
- It creates libftprintf.a directly with ar.

Example after:
NAME = libftprintf.a
SRC = ft_printf.c \
	ft_helpers.c

Why:
- You removed libft, so the build had to become standalone.

2) printf formatter dependency fix

Before:
- ft_printf.c called libft functions that no longer exist in this project.
- These calls were: ft_putchar_fd, ft_putstr, and ft_putnbr.

Example before:
if (c == 'c')
	return (ft_putchar_fd(...), 1);
else if (c == 's')
	return (ft_putstr(...));
else if (c == 'd' || c == 'i')
	return (ft_putnbr(...));

After:
- ft_printf.c now uses your local helper functions.
- %c uses write directly.
- %s uses ft_putstr_pf.
- %d and %i use ft_putnbr_pf.

Example after:
if (c == 'c')
	return (write(1, &(char){(char)va_arg(args, int)}, 1));
else if (c == 's')
	return (ft_putstr_pf(va_arg(args, char *)));
else if (c == 'd' || c == 'i')
	return (ft_putnbr_pf((long)va_arg(args, int)));

Why:
- The code now links against functions that actually exist in this repository.

3) trailing percent bug fix

Before:
- If the format string ended with %,
  the loop could advance past the end of the string.

Example before:
ft_printf("%");

After:
- The code now prints the literal % and stops safely.

Example after:
ft_printf("%");

Why:
- This prevents reading invalid memory at the end of the format string.

4) signed integer safety fix

Before:
- ft_putnbr_pf did n = -n for negative values.
- That is unsafe for LONG_MIN.

Example before:
if (n < 0)
{
	write(1, "-", 1);
	n = -n;
}

After:
- ft_putnbr_pf converts the magnitude safely through an unsigned value.

Example after:
if (n < 0)
{
	write(1, "-", 1);
	magnitude = (unsigned long)(-(n + 1)) + 1;
}

Why:
- This avoids undefined behavior on the most negative long value.

5) pointer formatting portability fix

Before:
- ft_putptr_pf passed the pointer value through a mismatched integer type.

Example before:
ft_puthex_pf((unsigned long long)ptr, HEX_LOW);

After:
- The hex helper accepts unsigned long long, so pointer formatting is handled more consistently.

Example after:
int ft_puthex_pf(unsigned long long n, char *base)

Why:
- This reduces the risk of truncation on wider pointer platforms.

Current result
- The project builds successfully with make fclean && make.
- The archive produced is libftprintf.a.
